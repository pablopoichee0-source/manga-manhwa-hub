# MoonWave Manga & Manhwa

Sitio web de manga y manhwa con diseño moderno, responsive y catalogo dinámico.

## Cómo abrir el sitio

Puedes abrir directamente `index.html` en el navegador o usar un servidor local:

```bash
python -m http.server 8000
```

Luego visita:

http://localhost:8000

## Estructura

- `index.html` — estructura principal
- `styles.css` — estilos visuales
- `script.js` — catálogo dinámico y filtros

## Personalización

Puedes editar el array de series en `script.js` para agregar más títulos, imágenes y categorías.

## Stack

Proyecto frontend estático con HTML, CSS y JavaScript.
