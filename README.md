# MoonWave Manga & Manhwa

Sitio web de manga y manhwa con diseño moderno, responsive y lector integrado.

## Cómo abrir el sitio

Puedes abrir directamente `index.html` en el navegador o usar un servidor local:

```bash
python -m http.server 8000
```

Luego visita:

http://localhost:8000

## Características

- Landing page premium
- Biblioteca con buscador y filtros
- Detalles de cada manga/manhwa
- Lista de capítulos interactiva
- Lector tipo web con páginas
- Diseño responsive para móvil y escritorio

## Estructura

- `index.html` — estructura principal
- `styles.css` — estilos visuales y modal/lector
- `script.js` — catálogo dinámico, filtros y lectura

## Personalización

Puedes editar el array de series en `script.js` para agregar más títulos, autores, imágenes y capítulos.

## Stack

Proyecto frontend estático con HTML, CSS y JavaScript.
